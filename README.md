# Radial Tool (Native Win32 C++)

Lightweight, high-performance Radial Context Menu and Quick Launcher for Windows written in pure native C++ (Win32 API & GDI+).

## Highlights
- **Ultra Lightweight**: Only ~1 MB standalone executable, 0% CPU at idle, ~5–10 MB RAM footprint.
- **Hold-Aim-Release Navigation**: Hold mouse trigger (M4/M5), aim towards desired sector, and release to execute instantly.
- **Cancel Button Hub**: Release or click in center circle (`✕ BATAL`) to safely cancel.
- **Multi-Page Scroll**:
  - **Media Page**: Format Image conversion, Image to PDF merge, Smart Screenshot tool, Image Compression, PDF Split.
  - **Web Page**: Quick launch for YouTube, Netflix, GitHub, ChatGPT, and Google.
- **No External Dependencies**: Zero Electron, zero web runtime overhead. Direct native Windows binary.
